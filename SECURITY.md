# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Instead, contact the maintainer privately via GitHub or the project contact channels and provide:

- a description of the vulnerability,
- affected versions or components,
- reproduction steps if possible,
- severity assessment and impact,
- any suggested mitigation.

We will investigate and respond as quickly as possible.

## Supported versions

This project is under active development. Security updates will be provided for the current version in active development and the latest released version when applicable.

## Disclosure policy

We ask that vulnerabilities be reported privately first so that a fix can be prepared before public disclosure.
