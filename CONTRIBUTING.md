# Contributing

Thanks for your interest in contributing to this project.

## How to contribute

- Open an issue before starting significant work.
- Keep changes focused and minimal.
- Follow the existing code style and project conventions.
- Add or update tests when appropriate.
- Update documentation when behavior or setup changes.

## Development setup

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the app in development mode:
   ```bash
   npm run dev
   ```

## Branching and pull requests

- Create a feature branch for your work.
- Keep pull requests small and reviewable.
- Include a clear summary of the change and testing done.
- Rebase or merge the latest main branch before opening a PR when needed.

## Code standards

- Prefer simple, readable solutions.
- Do not add unrelated refactors.
- Respect the project’s existing patterns and naming.

## Reporting issues

Please use the GitHub issue templates and include:

- clear reproduction steps,
- expected vs actual behavior,
- environment details,
- relevant logs or screenshots.

By contributing, you agree that your work will be licensed under the GPL-3.0 license.
